# 🚫 Как банить пользователей

## Что делает бан система?

Когда пользователь забанен через админ-панель:
- ❌ Не может создавать посты
- ❌ Не может взаимодействовать с сайтом
- ❌ Видит экран блокировки с сообщением
- ✅ Может связаться с админом через Telegram

## Как забанить пользователя

1. Открой админ-панель: `admin.html`
2. Найди пользователя в таблице "👥 Пользователи"
3. Нажми кнопку "Забанить" рядом с его именем
4. Подтверди действие

## Как разбанить пользователя

1. Открой админ-панель: `admin.html`
2. Найди забаненного пользователя (статус "🚫 Забанен")
3. Нажми кнопку "Разбанить"
4. Пользователь снова может пользоваться сайтом

## Что видит забаненный пользователь?

При попытке войти на сайт он увидит:
- 🚫 Большой значок блокировки
- Заголовок "Доступ заблокирован"
- Сообщение о том, что аккаунт заблокирован
- Ссылку на Telegram админа: t.me/imCEOmf

## Технические детали

### Проверка бана происходит:
1. При входе через Google OAuth (`handleGoogleCallback`)
2. При загрузке страницы (`checkAuth`)

### Где хранится информация о бане:
- В таблице `beceo_users` в Supabase
- Поле `is_banned` (true/false)

### Файлы с кодом бан-системы:
- `app.js` - функции `showBanScreen()`, проверки в `checkAuth()` и `handleGoogleCallback()`
- `index.html` - HTML разметка экрана бана (`#banScreen`)
- `style.css` - стили для экрана бана (`.ban-screen`, `.ban-content`)
- `admin.html` - кнопки бана/разбана в админ-панели

## Примечания

- Бан проверяется автоматически при каждом входе
- Забаненный пользователь не может обойти блокировку
- Все данные пользователя сохраняются (посты, лайки)
- После разбана пользователь получает полный доступ обратно
