# Настройка Админ-Панели BE CEO

## ⚠️ ВАЖНО: Текущее состояние

**Сейчас сайт использует localStorage** - все посты хранятся локально в браузере каждого пользователя.

**Админ-панель работает с Supabase** - централизованная база данных.

Чтобы управлять постами, нужно:
1. Настроить Supabase (шаги ниже)
2. Интегрировать Supabase в основной сайт (я могу это сделать)

После интеграции все новые посты будут в базе данных, и ты сможешь их удалять/редактировать через админ-панель.

---

## Шаг 1: Создай таблицы в Supabase

1. Открой [Supabase Dashboard](https://app.supabase.com/)
2. Выбери свой проект
3. Перейди в **SQL Editor** (слева в меню)
4. Нажми **New Query**
5. Скопируй весь код из файла `supabase_setup.sql`
6. Вставь в редактор и нажми **Run**

Это создаст:
- Таблицу `users` (пользователи)
- Таблицу `traces` (посты/следы)
- Таблицу `likes` (лайки)
- Все индексы и политики безопасности
- Функцию для статистики

## Шаг 2: Настрой админ-панель

1. Открой файл `admin.html`
2. Найди строки:
```javascript
const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

3. Замени на свои данные из Supabase:
   - **SUPABASE_URL**: Project Settings → API → Project URL
   - **SUPABASE_ANON_KEY**: Project Settings → API → anon public key

## Шаг 3: Сделай себя админом

После первого входа на сайт через Google, выполни в SQL Editor:

```sql
-- Замени 'твой_username' на свой username
UPDATE users 
SET is_admin = true 
WHERE username = 'твой_username';
```

Или найди свой ID и обнови:

```sql
-- Посмотри всех пользователей
SELECT * FROM users;

-- Сделай себя админом по ID
UPDATE users 
SET is_admin = true 
WHERE id = 'твой-uuid-здесь';
```

## Шаг 4: Открой админ-панель

Просто открой `admin.html` в браузере или залей на GitHub Pages.

## Возможности админ-панели:

✅ **Статистика:**
- Количество пользователей
- Количество следов
- Общее количество лайков
- Количество забаненных

✅ **Управление следами:**
- Просмотр всех постов
- Удаление любого поста
- Сортировка по дате

✅ **Управление пользователями:**
- Просмотр всех пользователей
- Бан/разбан пользователей
- Просмотр email и даты регистрации

## Безопасность:

⚠️ **Важно:** Админ-панель использует `anon` ключ, который безопасен благодаря Row Level Security (RLS).

Политики RLS гарантируют что:
- Только админы могут удалять следы
- Только админы могут банить пользователей
- Обычные пользователи не могут изменять чужие данные
