# BE CEO - Оставь свой цифровой след

Платформа для создания и просмотра цифровых следов с авторизацией через TikTok.

## 🚀 Концепция

**BE CEO** - это социальная платформа, где каждый пользователь может оставить свой уникальный "цифровой след" - короткое вдохновляющее сообщение, которое будет видно всем.

### Основные правила:
- ✅ Один пользователь = один след (навсегда)
- ✅ Авторизация только через TikTok
- ✅ След нельзя изменить или удалить
- ✅ Другие пользователи могут лайкать следы
- ✅ Есть сортировка по новизне и популярности

## 🎨 Дизайн

Дизайн выполнен в стиле **OSINT Cabinet**:
- Тёмная тема с градиентами
- Неоновое свечение заголовка
- Glassmorphism эффекты
- Плавные анимации
- Адаптивная вёрстка

## 🔧 Функционал

### Для неавторизованных:
- Просмотр всех следов
- Сортировка по новизне/популярности
- Статистика (общее количество следов и лайков)

### Для авторизованных:
- Создание своего следа (один раз)
- Лайки на следы других пользователей
- Просмотр своего профиля

## 🔐 Авторизация через TikTok

### Текущий статус: 🚧 В разработке

Для интеграции с TikTok потребуется:
1. Создать приложение в TikTok Developer Portal
2. Получить Client Key и Client Secret
3. Настроить OAuth 2.0 flow
4. Добавить redirect URL

### Временное решение:
Сейчас используется демо-авторизация для тестирования функционала.

## 💾 Хранение данных

### Текущая версия (LocalStorage):
- `beceo_user` - данные текущего пользователя
- `beceo_traces` - все следы
- `beceo_likes` - лайки пользователей

### Будущая версия (Backend):
Планируется использовать:
- **Supabase** для базы данных
- **TikTok OAuth** для авторизации
- **Cloudflare Pages** для хостинга

## 📊 Структура данных

### Trace (След):
```javascript
{
  id: number,
  username: string,
  avatar: string,
  message: string,
  date: Date,
  likes: number
}
```

### User (Пользователь):
```javascript
{
  id: number,
  username: string,
  avatar: string,
  tiktok_id: string
}
```

## 🚀 Запуск

Просто откройте `index.html` в браузере:
```bash
start index.html
```

Или используйте локальный сервер:
```bash
python -m http.server 8000
```
