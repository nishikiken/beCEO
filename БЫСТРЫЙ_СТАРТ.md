# 🚀 Быстрый старт BE CEO

## Шаг 1: Откат (если нужно)
Если ты уже запускал SQL раньше, выполни в Supabase SQL Editor:
```sql
-- Код из файла ОТКАТ_ТАБЛИЦ.sql
DROP TABLE IF EXISTS beceo_likes CASCADE;
DROP TABLE IF EXISTS beceo_traces CASCADE;
DROP TABLE IF EXISTS beceo_users CASCADE;
DROP FUNCTION IF EXISTS beceo_update_trace_likes() CASCADE;
DROP FUNCTION IF EXISTS beceo_get_stats() CASCADE;
```

## Шаг 2: Создай таблицы
Выполни в Supabase SQL Editor весь код из файла `supabase_setup.sql`

## Шаг 3: Протестируй
1. Открой `index.html` → зарегистрируйся → создай пост
2. Открой `admin.html` → увидишь данные

**Готово!** Никаких прав админа настраивать не нужно - админ-панель работает для всех (она локальная).
