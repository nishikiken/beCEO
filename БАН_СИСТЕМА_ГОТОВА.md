# ✅ БАН-СИСТЕМА ГОТОВА!

## Что реализовано

### 1. Экран блокировки для забаненных пользователей
- Полноэкранный экран с сообщением о блокировке
- Анимированная иконка 🚫
- Информация о причине блокировки
- Ссылка на Telegram админа: t.me/imCEOmf
- Скрывает весь контент сайта (header, footer, секции)

### 2. Автоматическая проверка бана
- При входе через Google OAuth
- При загрузке страницы
- Проверяет поле `is_banned` в таблице `beceo_users`

### 3. Админ-панель с управлением банами
- Кнопка "Забанить" для активных пользователей
- Кнопка "Разбанить" для забаненных пользователей
- Статистика забаненных пользователей
- Статус пользователя (✅ Активен / 🚫 Забанен)

## Файлы с изменениями

### `app.js`
- Функция `showBanScreen()` - показывает экран блокировки
- Проверка бана в `checkAuth()` - при загрузке страницы
- Проверка бана в `handleGoogleCallback()` - при входе через Google

### `index.html`
- Добавлен `<div id="banScreen">` с экраном блокировки
- Структура экрана с иконкой, заголовком, сообщением и ссылкой

### `style.css`
- Стили для `.ban-screen` - полноэкранный оверлей
- Стили для `.ban-content` - контейнер с glassmorphism
- Стили для `.ban-icon` - анимированная иконка
- Стили для `.ban-contact` - кнопка Telegram

### `admin.html`
- Функция `banUser(id)` - банит пользователя
- Функция `unbanUser(id)` - разбанивает пользователя
- Кнопки бана/разбана в таблице пользователей
- Счетчик забаненных пользователей в статистике

## Как это работает

1. **Пользователь входит на сайт**
   - Проверяется `is_banned` в Supabase
   - Если `true` → показывается экран блокировки
   - Если `false` → нормальная работа сайта

2. **Админ банит пользователя**
   - Открывает `admin.html`
   - Нажимает "Забанить" рядом с пользователем
   - В Supabase устанавливается `is_banned = true`

3. **Забаненный пользователь пытается войти**
   - Видит экран блокировки
   - Не может создавать посты
   - Не может взаимодействовать с сайтом
   - Может связаться с админом через Telegram

4. **Админ разбанивает пользователя**
   - Нажимает "Разбанить"
   - В Supabase устанавливается `is_banned = false`
   - Пользователь снова может пользоваться сайтом
